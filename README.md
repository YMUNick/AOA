# AOA · 面試即時翻譯助手

英文即時字幕、繁體中文翻譯，以及由你圈選後才產生的 AI 回答。深藍黑、青藍與電光紫工作台，支援桌面與手機排版。

**網站：[https://ymunick.github.io/AOA/](https://ymunick.github.io/AOA/)**

## 開始使用

1. 用新版桌面 Chrome 開啟網站，也可以先按「先試用示範」。示範不收音、不呼叫付費服務。
2. 選「本機翻譯」，按「準備翻譯」下載所需模型。若瀏覽器不支援，仍可使用英文字幕，或明確選擇會計費的雲端翻譯。
3. AI 回答可選 OpenAI 或 Gemini，填入自己的 API 金鑰；或者連到自己的安全代理。沒有金鑰仍可使用已就緒的本機翻譯與字幕。
4. 按「開始聆聽」並允許麥克風。網站使用系統預設麥克風，不擷取 Teams／Zoom 系統音訊。
5. 反白字幕或按「選取整段」，再按「產生回答」。可取得英文建議與中文重點，也能選用 STAR 架構。
6. 訪談結束後按「匯出」，下載逐字稿與最近一次回答；開始新訪談或重新整理會清除內容。

手機與桌面都會持續往下追加完整逐字稿，每段英文下方顯示對應的繁體中文。說話中的文字先在底部更新，完成後才加入紀錄與翻譯。畫面預設跟隨最後一句；往上滑或選取文字時停留原位，新內容仍會加入下方。按「回到最新」或滑回底部可恢復跟隨，不需要切換歷史字幕。手機的時間與費用可從「用量」查看。

中英對照需要已就緒的本機翻譯，或明確選用雲端翻譯。已測 Android 手機不支援本機翻譯：在首頁選「雲端翻譯」與「OpenAI」，填入自己的 OpenAI API 金鑰後開始新訪談；同一把金鑰也用於回答助手。雲端會對新完成的片段計費，回答仍只在按下「產生回答」時呼叫。金鑰只填在網站，請勿貼到聊天或 repo。

手機或不支援語音辨識的瀏覽器，可按「貼上英文」手動加入文字。單一麥克風也會收進自己的聲音，網站不會假裝知道說話者身分。

## 字幕與傳送頻率

不是固定每幾秒傳送。Chrome 的語音辨識先提供暫時英文字幕，判定片段完成（`isFinal`）後才加入逐字稿並排入翻譯；停頓、說話速度與網路都會影響完成時間。原始音訊的傳輸由瀏覽器管理，網站沒有設定音訊封包間隔。

Android 使用單句辨識並自動接續下一句，避免已測 Chrome 155 將說話中的片段反覆當成完成句。正常完成後約 0.5 秒重新聆聽；未辨識到文字時約 1 秒重試，不消耗網路錯誤的重試次數。這些是重新啟動的等待時間，不是音訊傳送間隔；切換時仍可能漏字。

本機翻譯不呼叫付費翻譯 API；選用雲端翻譯時，只傳新完成的文字片段。AI 回答只在按下「產生回答」時送出，並非每段字幕都自動產生回答。

## 費用與資料

估算牌價更新於 **2026-10-14**。每小時 20 次回答，每次約 1,500 輸入、500 輸出 tokens，含 20% 餘裕：

| 模型 | 本機翻譯＋20 次回答 | 雲端文字翻譯＋20 次回答 |
|---|---:|---:|
| OpenAI `gpt-6-luna` | 約 US$0.01 | 約 US$0.03–0.05 |
| Gemini `gemini-3.5-flash-lite` | 約 US$0.04 | 約 US$0.12–0.19 |

不含另外購買的語音 API、代理服務、稅或匯差。模型可用性與牌價以供應商為準；這些是工程估算，不是實測帳單。API 計費與 ChatGPT／Codex 訂閱分開。

- 本機翻譯沒有額外翻譯 API 費；瀏覽器語音辨識可能透過瀏覽器廠商的雲端服務處理，因此不宣稱全程離線。
- 雲端翻譯只傳送新完成片段；回答只傳圈選內容、有限前文及你提供的背景，不反覆傳整場逐字稿。
- 金鑰、逐字稿與背景預設只留在分頁記憶體；不寫入 localStorage、repo 或網站伺服器。不錄製或儲存音訊。
- 個人金鑰模式會把金鑰交給目前頁面的程式，因此只供個人自用；記憶體儲存不等於秘密隔離。正式使用建議部署自己的安全代理。
- 費用欄包含已知用量及進行中／待確認的預留費用；取消或失敗仍可能計費。達預算後停止新的付費請求，不影響本機字幕。
- 前端預算是本次分頁的防護，重新整理可重置，不是供應商帳戶的硬上限。私人代理另有持久化每日預算，跨 session 保留。
- 模型回覆一次完成後顯示，等待時有明確狀態與取消按鈕。未提供真實經歷時使用可替換框架，不應把範例直接當作自身經驗。

## 本機開發

需要 Node.js 24。

```sh
npm ci
npm run dev
```

開啟終端顯示的 `/AOA/` 網址。

```sh
npm test
npm run check
npm run build
npm run preview
```

目前 145 項單元與整合測試涵蓋字幕去重、停止／重連、Android 未匹配語音恢復、單句辨識、中英逐字稿累積、往上閱讀及底部跟隨、選字保留、翻譯完成後的版面更新、翻譯不可用提示、demo 隔離、過期回應、API 錯誤、預算預留與代理驗證，另含加速的一小時模擬與手機原生選字事件。計時使用實際經過時間，重連和延遲的畫面更新不會逐次少算秒數。

Samsung SM-N981B／Chrome Android 155 已實機驗證鍵盤彈出、螢幕鍵盤英文輸入、送出／收起、原生長按、拖曳選字控制點，以及切到回答助手後保留選取文字。混合中英文字的提交有驗證，中文輸入法組字尚未實測。桌面／手機瀏覽器功能測試中的翻譯與付費 API 使用模擬回應，沒有產生付費請求。

後續實體手機麥克風短測確認可收到使用者說話並產生英文字幕。修正前，Android 的 `nomatch` 會耗盡重試而誤停，連續辨識也會將部分文字重複加入紀錄；單句模式實測改為暫時結果更新後才留下完成句。手機本機翻譯 API 不可用，因此這項實測關閉翻譯與 AI，未驗證付費翻譯或回答。手機短測與以下桌面一小時測試是不同範圍。

**2026-10-14 已完成 60 分鐘 Chrome 原生辨識與自動恢復驗證。** 使用合成英文音訊軌，實際運行 3,600.034 秒；738 段完成辨識對應 738 段畫面字幕，61 次每分鐘紀錄均持續增加，計時顯示 `01:00:00`。辨識服務回報 11 次 `network` 錯誤，均自動重連後繼續產生字幕；兩段完成字幕間最長相隔 11.291 秒。這是字幕間隔，不是端到端翻譯延遲，也不證明重連期間沒有漏字。

抽樣 JavaScript heap 使用量約 4.19–33.37 MB；每分鐘雙畫面更新檢查為 5–46 ms，沒有觀察到當機或未回應。按下結束後兩秒內沒有再啟動辨識，測試程序正常退出。翻譯與 AI 回答在這項長測中關閉，付費 API 請求為 0。數據見[驗證摘要](docs/verification/2026-10-14-speech-soak.json)。

上述一小時結果對應提交 `659e1f3`，後續 Android 單句與手機閱讀修正另行通過短測及回歸測試，沒有宣稱已完成手機一小時測試。**這些結果不代表實體麥克風或真實面試能全程零中斷、零漏字**。長測依使用者選擇，以合成音訊送入真實桌面 Chrome 辨識；iOS、背景休眠、藍牙切換、本機翻譯與付費服務的一小時表現仍需各自驗證。

## GitHub Pages

`.github/workflows/deploy.yml` 在 `main` 更新時執行測試、建置並部署 `dist`。

- repo Settings → Pages → Source 選 **GitHub Actions**。
- 專案 base path 固定為 `/AOA/`，使用同頁狀態切換，不需要伺服器路由。
- GitHub Pages 只部署前端，不能執行 API 代理或存放秘密。**不要把 API key 寫進 `VITE_*` 環境變數。**

## 安全代理（選用）

`worker/` 提供 Cloudflare Worker＋SQLite Durable Object，支援 OpenAI。包含短效會話驗證、登入限流、固定上游、文字／輸出上限、request ID 去重與原子每日預算。provider key 放在 Worker secrets。

請依 [worker/README.md](worker/README.md) 設定自己的 Cloudflare 帳戶與秘密並部署。前端上線不代表代理已上線。未設定代理時，可用個人金鑰模式。
